How Client-Side Scanning Works

Unlike cloud-based security tools that send your text to third-party language models or backend APIs for processing, KLYVORQ executes 100% of its regex evaluation and Luhn verification locally in your web browser.

Supported Detection Patterns

  • Email Addresses: Compliant RFC regex scanning for user and domain email patterns.
  • Phone Numbers: Detects North American (NANP), UK, and international E.164 phone formats.
  • IPv4 Addresses: Scans for four dot-separated decimal octets and strictly validates each octet is between 0 and 255.
  • Payment Card Patterns: Matches 13 to 19 digit number sequences and validates the sequence format against the international Luhn Modulo 10 Checksum Algorithm.

Practical Real-World Scenario: Sanitizing Developer Support Logs

Consider a software engineer preparing to post a crash trace to an open GitHub issue or vendor forum. Raw logs often contain incidental user credentials and internal server IPs:

User session crash for account dev@clientcompany.com on gateway 192.168.1.104; support contact: +1 (555) 019-2834.

Running this text through the Sensitive Info Scanner immediately flags:

  • 1 Email Address: dev@clientcompany.com
  • 1 Valid IPv4 Address: 192.168.1.104
  • 1 International Phone Number: +1 (555) 019-2834

The engineer can sanitize or redact these sensitive tokens with one click before publishing, eliminating compliance risks without sending private data to an external server.

Frequently Asked Questions

Does a payment card match mean the card is active or valid?
No. The tool performs a mathematical format checksum validation (Luhn algorithm) only. It does not check bank issuing status, expiration dates, CVVs, account balances, or fraud databases. It is designed solely to help you sanitize text before publishing logs or customer tickets.
Can I safely paste confidential customer notes?
Yes. You can verify this by checking your browser's Developer Tools (Network Tab): zero network requests are initiated when typing or scanning text in this tool.
